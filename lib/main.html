How to link device

  1. Neeche apna WhatsApp number likho (country code ke sath).
  2. Get Pair Code button dabao.
  3. WhatsApp open karo → Linked Devices → Link a Device.
  4. Phone number se link choose karo, phir yahan wala code enter karo.
  5. Code 1 minute me expire ho sakta hai, turant use karo.

Sirf digits. Plus (+) ya leading 0 mat likho.
Format example: 92xxxxxxxxxx
